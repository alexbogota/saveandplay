## Где главное
- `data/accounts.json`: всё про аккаунты и каналы (правила выбора скидок, шаблоны постов, теги, пометка `Ad`, лимиты). Новый канал или аккаунт = новый блок, код не меняется.
- `data/deals.json`, `data/history.json`: скидки и история цен, их пишет бот. `scripts/daily-brief.mjs`, `scripts/update-deals.mjs`, `scripts/lib/posts.mjs`: ежедневные программы и сборка постов. `scripts/article-tools.mjs`, `data/articles.json`, `docs/article-writer.md`: автор статей.
- `src/` сайт, `.github/workflows/` расписания, `docs/` длинные записи (Quora: `docs/quora.md`), `NOSTR.md` всё про Nostr, `LEMMY.md` всё про Lemmy, `TUMBLR.md` всё про Tumblr. `docs/add-account.md` как добавить новый аккаунт Bluesky, `CLAUDE.md` дизайн и правила, `PROJECT.md` оглавление, `SOURCES.md` источники новостей.

## Как запускать
- `npm run build` собрать сайт, `npm run dev` посмотреть его. `npm run brief` локально собрать бриф и посты в `drafts/`. `npm run update-deals -- --dry-run` пробное обновление цен.
- Проверки: `npm run posts:test`, `npm run nostr:test`, `npm run kinguin:test`, `npm run articles:test`, `npm run lemmy:test`, `npm run tumblr:test`, `npm run comments:test`, `npm run social:test`. Теги: `npm run tags:research`.
- На GitHub: Actions, нужный workflow, кнопка Run workflow. Не «Re-run»: он берёт старый код.

## Главные правила
- Пометка рекламы: строка `Ad` обычным текстом, последняя строка поста. Не `#ad`.
- В постах ссылки только на наши страницы `/deals/...`, не прямо в магазин.
- Настройки аккаунтов и каналов только в `data/accounts.json`. Код под один аккаунт не пишем.
- Цифры только из `data/deals.json`. Ничего не выдумывать, «lowest ever» не писать.
- Бот пишет `data/*.json`: перед правкой данных сделать `git pull`. Секретов в файлах нет. Максимум автоматизации: рутину владельцу не поручать. Одна задача за раз, следующую не предлагать.
- Владельцу писать по-русски, просто и коротко. Тексты сайта и постов только по-английски.
- Тяжёлые загрузки (товарные фиды любых магазинов и ниш) делаем только в публичном репозитории `saveandplay-feeds`: там минуты GitHub Actions бесплатны, а в приватном лимит 2000 в месяц. Основной репозиторий с 20 октября временно открыт (Public, минуты бесплатные): бесплатные минуты кончились из-за ошибки в скриптах; перед тем как его закрыть, посчитать расход минут всех программ вместе с отправкой ответов. Новая ниша или фид = строка в его `data/feeds.json`. Основной репозиторий читает готовый маленький файл по ссылке. Ключи фидов только в секретах того репозитория.
- Оффер с запретом на соцсети (например War Thunder) в посты не ставить. Перед продвижением любого оффера открыть его правила в Admitad (Rules).
- Пост со ссылкой на нашу статью: сначала убедиться, что статья открывается на сайте, и вставить ссылку в окно поста: должна появиться карточка с картинкой и заголовком. Карточка Bluesky записывается в пост при публикации и потом не обновляется, пост с пустой карточкой нужно удалить и выложить заново.
- Решение изменилось: запись в `docs/decisions.md`, здесь только итог.
