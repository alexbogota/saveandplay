# Tumblr: всё про эту площадку

Создано 12 октября 2026. Вернуться: [START.md](START.md), [docs/channels.md](docs/channels.md). Решение записано в `docs/decisions.md` (запись «Tumblr как новая площадка»).

## Статус
Код, настройки, расписание и тесты готовы (`npm run tumblr:test`, 34 проверки). **Всё выключено**: `autopost: false`, а имя блога в настройках пока заглушка. Программа ни разу не работала с настоящим Tumblr (из рабочей среды чата его не достать), тесты идут на подделке сервера, которая сама проверяет подпись запросов. Поэтому первый шаг после создания блога: Actions → Post to Tumblr → mode `check`.

## Почему Tumblr и почему так (решение владельца 12 октября)
- Все ссылки в постах ведут на НАШИ страницы (`/deals/...`, `/guides/...`), не в магазины. Партнёрки (GOG, IndieGala) уже разрешают такие посты в Bluesky и Mastodon, владелец считает, что Tumblr подходит так же. Отдельно добавлять Tumblr площадкой в Admitad и Sovrn не нужно (исключение из §5 `docs/channels.md`, только для Tumblr).
- Что публикуется то же, что в Nostr и Lemmy: скидка дня и гиды сайта. Чужие новости не репостим.
- Tumblr даёт охват и долгую жизнь постов (ребло́г, поиск по тегам), но кликов с него ждать немного. Это эксперимент, не основной канал.

## Что публикуется
- **Скидка** (`--kind deal`), раз в день в 08:00 по Боготе: первая скидка брифа из блока `tumblr` в `data/accounts.json` (GOG и IndieGala, от 50%). Пост из блоков: заголовок «Игра: -85% at Магазин», обложка (с alt-текстом `Cover art for …`), цена и старая цена, дата проверки, конец акции, «Why today», блок-ссылка на НАШУ страницу игры (`utm_source=tumblr-prices`), последним блоком `Ad: we may earn a commission if you buy.` Теги: общие, магазина и название игры.
- **Гид** (`--kind article`), в 13:00, не чаще раза в 2 дня (`articleEveryDays`): самый старый ещё не выложенный гид, только если его страница открывается. Заголовок, картинка с `imageAlt`, описание, блок-ссылка на гид. Пометки `Ad` нет: гид ведёт на наш сайт. Не пускать гид в Tumblr: `tumblr: false` в шапке.
Текст собирает программа по шаблону, без нейросети. Цифры только из `data/deals.json` через бриф. Размер картинок (Tumblr его требует) программа читает из самой картинки, руками ничего не вводится.

## Картинки и размеры (12 октября)
- Проблема: ссылку на нашу страницу Tumblr превращал в карточку и сам резал картинку по краям (на скриншоте владельца обрезано слово SaveAndPlay), размер карточки программа задать не может. Официального размера карточки у Tumblr нет: в [описании на tumblr.com](https://www.tumblr.com/unwrapping/75873529443/dashboard-image-sizes) сказано только «540 px шириной, картинка берётся со страницы».
- Решение: пост не использует карточку. Картинка идёт отдельным блоком `image` со своими настоящими размерами (их программа читает из файла), под ней строка-ссылка на нашу страницу. Одиночную картинку Tumblr показывает целиком, без обрезки, шириной 540 px (официально: хранит до 1280 px шириной и 1920 высотой). Вернуть карточку можно настройкой `linkStyle: "card"` в `data/tumblr-accounts.json`.
- Какие картинки нужны: для гидов `public/og/<имя>.png` 1200×630 подходят как есть (при показе 540 px это запас для чёткости на экранах Retina; Tumblr берёт не больше 1280 px шириной). Если рисуете новую картинку специально: 1280×670 (то же 1.91:1) или 1280×720, главное внутри, не у края. Обложки скидок идут из Steam (460×215): Tumblr растягивает их до 540 px, немного мягче, но целиком.
- Откуда на скриншоте большая зелёная кнопка «play» поверх картинки, я не выяснил: в описании Tumblr её нет. Если она появится и у картинки-блока, пришлите скриншот именно такого поста.

## Что делает владелец (один раз)
1. Создать блог на tumblr.com (имя блога = часть до `.tumblr.com`). Описание блога (например: «Honest PC game prices, checked daily. Posts are made by a bot. Some links are affiliate links, we may earn a commission. saveandplay.com») и аватар поставить в настройках блога: автоматически это не делается (в API нет подтверждённого способа, это самый маленький оставшийся ручной шаг).
2. Зарегистрировать приложение: https://www.tumblr.com/oauth/apps → Register application. «Default callback URL» ровно `http://localhost:8765/callback` (в «OAuth2 redirect URLs» то же). Остальные поля любые (сайт: saveandplay.com). Ключ «OAuth Consumer Key» и «Secret Key» записать в локальный `.env`: `TUMBLR_CONSUMER_KEY=...` и `TUMBLR_CONSUMER_SECRET=...`.
3. `npm run tumblr:auth`. Программа печатает адрес и открывает браузер, вы входите в аккаунт блога и нажимаете Allow (единственное, что программа сделать не может). Токен и секрет токена сами запишутся в `.env`, на экране их нет. Программа покажет, какие блоги есть у аккаунта.
4. `npm run tumblr:secret`: четыре значения уходят в секреты GitHub (на экране не показываются).
5. В `data/tumblr-accounts.json` поправить `blog` на настоящее имя блога.
6. Попросить Claude Code закоммитить настройки Tumblr. Workflow уже на месте: `.github/workflows/post-tumblr.yml` (перенесён 12 октября), кнопка Post to Tumblr на GitHub есть.
7. GitHub → Actions → Post to Tumblr → Run workflow → mode `check` (вход и блог), потом `dry-run` (готовые тексты, ничего не публикуется). Прочитать правила Tumblr (раздел ниже), и только потом поставить `autopost: true`. Совет: сначала оставить в `kinds` только `article` (гиды без рекламы), скидки добавить через несколько дней, когда блог ожил.

## Как устроено
- `data/tumblr-accounts.json`: блог, теги, `kinds`, `autopost`. `data/accounts.json`, блок `tumblr`: правила подбора скидок для брифа. Ключи должны совпадать.
- `scripts/lib/tumblr.mjs` клиент, подпись запросов и шаблоны, `scripts/post-tumblr.mjs` постинг, `scripts/tumblr-check.mjs` проверка, `scripts/tumblr-auth.mjs` получение токена, `scripts/tumblr-secret.mjs` секреты в GitHub, `scripts/test-tumblr.mjs` тесты.
- Вход: OAuth 1.0a, четыре значения (consumer key и secret, token и secret). Они не устаревают, поэтому ничего не нужно обновлять и записывать обратно в GitHub. (OAuth 2 здесь хуже: токен живёт меньше часа, а новый выдаётся вместе с новым refresh-токеном, который пришлось бы сохранять между запусками.) Подпись проверена на примере из описания протокола.
- Запись о постах `posted-tumblr.json` лежит в ветке `brief` (сайт не пересобирается), её ведёт тот же `scripts/nostr-branch.sh` (`STATE_FILE`, `STATE_LABEL`).
- Один пост скидки в день. Не вышел: запуск красный, ничего не записано, следующий запуск пробует ТУ ЖЕ скидку.
- Вторая защита от дубля: перед постом программа смотрит последние 20 постов блога, и если там уже есть пост с той же нашей страницей (скидка: не старше 36 часов), считает его выложенным, даже если запись потерялась.
- Один блог = один блок. Второй блог = новый блок в обоих файлах (`secretPrefix` задаёт имена секретов, workflow получает четыре строки секретов нового блока).
- В заголовках запросов один и тот же User-Agent: Tumblr может отключить приложение, которое присылает разные.
- Лимиты Tumblr: 250 новых постов в день на пользователя, 1000 запросов в час на приложение. Нам нужно 2 поста в день.

## Что НЕ проверено (читать перед включением)
- Правила Tumblr про спам, автоматизацию и партнёрские ссылки. Страница правил не открылась для робота, я их не читал. Прочитать https://www.tumblr.com/policy/en/community (раздел про спам) и «Application Developer and API License Agreement» на tumblr.com/docs. Новые блоги, где одни ссылки, могут попасть под спам-фильтр: потому гиды идут первыми, а описание блога говорит, что посты автоматические.
- Живой Tumblr: вход по OAuth 1.0a для новых приложений, приём картинки по адресу (без загрузки файла) и карточка-ссылка из адреса страницы (Tumblr сам берёт заголовок и картинку из наших тегов og). Если `check` или первый пост вернут ошибку, текст ошибки и подсказка появятся в Summary запуска, и тогда это правка кода, а не ваша.
- Поведение при бане или ограничении аккаунта: `check` покажет HTTP 403.

## Что может пойти не так
- `HTTP 401`: ключи или токен неверны, или доступ приложения отозван. Снова `npm run tumblr:auth`, затем `npm run tumblr:secret`.
- `HTTP 400 (…)`: Tumblr не принял содержимое, причина в скобках. Скажите Claude Code, он поправит шаблон.
- `HTTP 429`: лимит, следующий запуск повторит.
- `tumblr:auth` пишет, что порт занят: закрыть программу на порту 8765 или задать другой порт переменной `TUMBLR_AUTH_PORT` и тот же в Default callback URL приложения.
