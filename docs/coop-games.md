# Игры для совместной игры: страницы и посты «играем вместе» (22 октября 2026, обновлено вечером)

Вернуться: [START.md](../START.md). Решение и причины: [decisions.md](decisions.md), запись 22 октября. Партнёр: [partners.md](partners.md) (Survival Servers).

## Что это
- Все игры, для которых Survival Servers сдаёт серверы, берёт программа `scripts/coop-build.mjs` (workflow «Update co-op games»: по понедельникам 05:30 Богота, по кнопке и когда меняются `data/coop-steam-ids.json` или `data/coop-host-games.json`). Steam здесь только справочник (многопользовательский режим, дата выхода, обложка), партнёрской ссылки на Steam нет. Программа берёт игру, только если Steam говорит: это вышедшая игра, есть режим для нескольких игроков, нет взрослого контента. Остальное она записывает в `data/coop-build-report.md` с причиной.
- 22 октября: 128 игр на их странице, из них 105 прошло (плюс 4 ручных: Stardew Valley, Core Keeper, Terraria, Necesse) = 109 страниц `/servers/<игра>/`, список `/servers/games/`. Страницы игр, сделанных программой, и этот список закрыты от поисковиков (`noindex`: много одинаковых страниц могут навредить сайту; открыть можно позже, когда появятся свои тексты). Игры из их списка «On the horizon» (серверов ещё нет) не берутся. Не берутся GTA 5 и Red Dead Redemption 2 (там серверы для модов), Minecraft и Hytale (нет в Steam: нет фактов и обложки, которой мы вправе пользоваться).
- Что неизвестно программе, она пишет в отчёт: ответ вносится в `data/coop-steam-ids.json` (номер Steam или `{"skip": "причина"}`), после этого сама пересобирается. Страницу хостинга она читает сама, но с GitHub её пока закрывает ответ 403, поэтому берёт сохранённый список (`data/coop-host-games.json`); новые игры хостинга появятся, когда страница откроется, или когда я их добавлю в список.
- Файл `data/coop-games.json`: одна игра = один блок (название, теги, факты с источниками, хостинг и его страница этой игры, готовые строки для постов, обложка Steam). Код при новой игре не меняется.
- Сайт сам делает страницу каждой игры `/servers/<slug>/` (`src/pages/servers/[game].astro`) и плитки игр на `/servers/`. Кнопка ведёт на страницу этой игры у хостинга с партнёрской меткой (`gameUrl` в `src/lib/hosts.ts`; у Survival Servers `?ref=alex70&trckit=site`, метка работает на любой их странице, проверено 22 октября).
- Посты «играем вместе» для Bluesky: `scripts/lib/coop-posts.mjs`, их показывает `node scripts/post-bluesky.mjs show` (то есть утренняя фраза «день saveandplay») вместе со скидками, одобряются тем же «ок все», выходят по часам после поста-скидки того же аккаунта. Без «ок» ничего не уходит.

## Настройка аккаунта (`data/accounts.json`, `channels.bluesky.coop`)
`{ "enabled": true, "anyTags": ["cozy"], "everyDays": 2, "baseTags": ["CozyGames"], "template": ["{text}", "{link}", "{tags}\n{disclosure}"] }`
- `anyTags`: аккаунт берёт игры, у которых есть хотя бы один из этих тегов.
- `everyDays`: не чаще одного такого поста за N дней.
- Игра: та, что этот аккаунт выкладывал давнее всех (новая первой); строка: следующая из `posts` игры по кругу.
- Ссылка только на нашу страницу игры, `utm_campaign=coop-<день>`, последняя строка `Ad` (на странице партнёрские ссылки), без цен.
- Сейчас включено: Cozy (`anyTags: ["cozy"]`: Stardew Valley, Core Keeper) и основной аккаунт (`prices`, `anyTags: ["*"]` = все 109 игр, раз в 2 дня; сначала ручные, потом по числу отзывов в Steam). Строки для игр программы делаются из того, что пишет Steam (есть ли кооператив), ничего сверх этого. Часы выкладки теперь через каждые 2 часа (было 3): у основного аккаунта до пяти постов в день, и последний должен выйти до 18:07 (`data/post-schedule.json`, `coop:prices` стоит перед Kinguin). Retro: старых игр с серверами в файле пока нет.

## Добавить игру
1. Найти игру в списке хостинга (survivalservers.com, Game Servers) и её страницу (`/services/game_servers/<имя>/`).
2. Факты только со страницы Steam игры и со страницы хостинга, с датой `checkedOn`. Цены не писать.
3. Обложка: `header_image` из ответа Steam `appdetails` (как у скидок).
4. 2–3 строки `posts` по-английски, без ссылок, тегов и цен; тест проверит длину для каждого аккаунта.
5. `npm run coop:test`, `npm run build`.
