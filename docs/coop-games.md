# Игры для совместной игры: страницы и посты «играем вместе» (22 октября 2026)

Вернуться: [START.md](../START.md). Решение и причины: [decisions.md](decisions.md), запись 22 октября. Партнёр: [partners.md](partners.md) (Survival Servers).

## Что это
- Файл `data/coop-games.json`: одна игра = один блок (название, теги, факты с источниками, хостинг и его страница этой игры, готовые строки для постов, обложка Steam). Код при новой игре не меняется.
- Сайт сам делает страницу каждой игры `/servers/<slug>/` (`src/pages/servers/[game].astro`) и плитки игр на `/servers/`. Кнопка ведёт на страницу этой игры у хостинга с партнёрской меткой (`gameUrl` в `src/lib/hosts.ts`; у Survival Servers `?ref=alex70&trckit=site`, метка работает на любой их странице, проверено 22 октября).
- Посты «играем вместе» для Bluesky: `scripts/lib/coop-posts.mjs`, их показывает `node scripts/post-bluesky.mjs show` (то есть утренняя фраза «день saveandplay») вместе со скидками, одобряются тем же «ок все», выходят по часам после поста-скидки того же аккаунта. Без «ок» ничего не уходит.

## Настройка аккаунта (`data/accounts.json`, `channels.bluesky.coop`)
`{ "enabled": true, "anyTags": ["cozy"], "everyDays": 2, "baseTags": ["CozyGames"], "template": ["{text}", "{link}", "{tags}\n{disclosure}"] }`
- `anyTags`: аккаунт берёт игры, у которых есть хотя бы один из этих тегов.
- `everyDays`: не чаще одного такого поста за N дней.
- Игра: та, что этот аккаунт выкладывал давнее всех (новая первой); строка: следующая из `posts` игры по кругу.
- Ссылка только на нашу страницу игры, `utm_campaign=coop-<день>`, последняя строка `Ad` (на странице партнёрские ссылки), без цен.
- Сейчас включено: Cozy (`cozy`: Stardew Valley, Core Keeper). Основной аккаунт (`prices`): блок есть, `enabled: false` (Terraria, Necesse по тегу `sandbox`), потому что у него уже 3–4 поста в день и пятый пост по часам вышел бы после 18:07 и пропал бы. Retro: подходящих старых игр с серверами в файле пока нет.

## Добавить игру
1. Найти игру в списке хостинга (survivalservers.com, Game Servers) и её страницу (`/services/game_servers/<имя>/`).
2. Факты только со страницы Steam игры и со страницы хостинга, с датой `checkedOn`. Цены не писать.
3. Обложка: `header_image` из ответа Steam `appdetails` (как у скидок).
4. 2–3 строки `posts` по-английски, без ссылок, тегов и цен; тест проверит длину для каждого аккаунта.
5. `npm run coop:test`, `npm run build`.
