# Разведка ниш для Quora (15 ноября 2026)

Вернуться: [START.md](../START.md). Правила самих ответов: [quora.md](quora.md). Решение: [decisions.md](decisions.md), запись 15 ноября.

## Что это
Программа `scripts/quora-scout.mjs` отвечает на вопрос «есть ли на Quora вопросы по этой теме и сколько». Годится для любой ниши и любого сайта, не только для игр. Она ничего не публикует и Quora не открывает (Quora закрыта для роботов): она спрашивает поисковик, какие страницы quora.com находятся по запросам ниши, и считает разные вопросы по теме. Если к нише подключены наши статьи, рядом с вопросом пишет статью, которая на него отвечает.

## Как запустить
- Фраза в чате Claude Code: «разведка quora: тема» (например «разведка quora: вышивка»). Claude добавит нишу в `data/quora-scout.json`, запустит программу и покажет отчёт.
- Руками: `npm run quora:scout` (все ниши), `npm run quora:scout -- --niche crafts-digital` (одна), `npm run quora:scout -- --topic "bullet journal, habit tracker"` (быстро посмотреть тему, которой нет в настройках).
- Отчёт: `drafts/quora-scout/report-<дата>.md`. Ответы поисковика сохраняются рядом (`raw-<дата>.json`), повторный запуск в тот же день поиск не тратит.
- Проверка программы: `npm run quora:scout:test`.

## Ключ поиска (один раз)
Программе нужен поисковик с разрешённым доступом для программ. Выбран Tavily: бесплатно 1000 поисков в месяц, карта не нужна (проверено по их документации 15 ноября 2026; Brave с февраля 2026 требует карту). Один запрос ниши = один поиск, ниша стоит до 12 поисков.
Шаг владельца: зарегистрироваться на tavily.com, скопировать ключ и добавить в файл `.env` строку `TAVILY_API_KEY=...`. В чат ключ не присылать.
Без ключа работает запасной путь: Claude в чате сам делает поиски (по 10 страниц на запрос) и передаёт их программе (`--from файл`). Так сделан первый отчёт 15 ноября.

## Как читать отчёт
- «Вопросов»: сколько разных вопросов по теме нашлось.
- «Из них точно в цель»: сколько вопросов про главный угол ниши (слова `focusWords`: «можно ли продавать», «лицензия», «коммерческое использование»). Под такие вопросы ответ прямо ведёт к товару. В списке они стоят первыми с пометкой «(в цель)». Это число важнее общего.
- «Доля»: какая часть найденных страниц оказалась вопросами по теме. Остальное: чужие темы, рекламные Spaces, повторы. 55% и выше = «вопросов много», от 30% = «вопросы есть, но не везде», ниже = «мало». Меньше трёх запросов = вывод предварительный.
- «Рекламных Spaces»: страницы-витрины внутри Quora. Много таких = тему уже заспамили (пример: бесплатные SVG для Cricut).
- «Есть наша статья»: под сколько вопросов нашлась статья. Это подсказка по совпадению слов в заголовке, перед ответом смотреть глазами.

Чего программа НЕ видит: сколько людей читает вопрос, сколько там ответов и насколько они хороши, дату вопроса. Пороги подобраны на глаз по первым нишам: сравнивайте ниши между собой, а не с абсолютной цифрой. Первые 5 вопросов выбранной ниши владелец открывает сам.

## Другие языки
У Quora есть отдельные сайты на других языках (es.quora.com, de.quora.com и так далее). Ниша с полем `lang` (например `"lang": "es"`) ищет только там; запросы и слова темы пишутся на этом языке. Проба 15 ноября (поиск из чата): на испанском 23 вопроса из 3 запросов, но точно в цель только 3 (на английском 24 из 64): вопросы общие («как продавать на Etsy»), про лицензии почти не спрашивают. Немецкий и французский: по одному запросу, около 3 подходящих вопросов из 10. Португальский: почти ничего. Вывод: начинать с английского, испанский проверить шире с ключом, остальные пока не брать.

## Категории Creative Fabrica
Кроме общего среза `crafts-digital` заведены девять ниш `cf-...` по видам товаров: шрифты, графика для print-on-demand, SVG и резка, вышивка, планеры, вязание, сублимация, раскраски и KDP, стикеры и Procreate. С ключом один запуск (около 100 поисков) покажет, какие категории дают больше вопросов «в цель». Список категорий составлен по памяти, не по сайту Creative Fabrica: владелец может добавить свои блоком в файл.

## Новая ниша или новый сайт
Новый блок в `niches` файла `data/quora-scout.json` (описание полей в его строке `about`): название, 5–10 запросов по-английски, слова темы, и где лежат статьи: папка с `.md` (`dir`, `base`), карта сайта (`sitemap`, `include`) или список вручную (`list`). Код не меняется.

## Первый отчёт (15 ноября 2026, поиск из чата, по 10 страниц на запрос)
- Темы Creative Fabrica (шрифты, SVG, вышивка, планеры, вязание, сублимация, print-on-demand): 64 вопроса из 8 запросов, доля 81%. Самые плотные: лицензии на шрифты и графику, «можно ли продавать связанное по чужой схеме», цифровые планеры, форматы вышивки (по 10 вопросов из 10). Слабые: «SVG для Cricut» (половина выдачи рекламные Spaces) и сам бренд Creative Fabrica (3 вопроса). Статьи этой ниши не подключены: нужен адрес сайта или папка.
- Старые игры на новом Windows: 16 вопросов из 2 запросов, под 14 подходит новый гид.
- Серверы: 10 вопросов из 2 запросов, половина выдачи про серверы для разработчиков, не для игроков.
- Game Pass, игры без видеокарты, баны Steam: по одному запросу, вопросов много, наших статей под них нет.
