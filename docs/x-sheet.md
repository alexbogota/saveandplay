# X (Twitter): посты из Google Таблицы (решение 21 октября 2026)

Назад: [START.md](../START.md). У X нет API для нас (платный и не нужен), поэтому владелец копирует готовый текст в X руками; программа делает всё остальное.

## Как устроено
1. В `data/accounts.json` у аккаунтов `prices`, `prices-2` (вторая игра дня), `cozy` и `retro` есть канал `x` (метки `x-prices`, `x-cozy`, `x-retro`, до 2 тегов, `Ad`, лимит 270 с запасом до 280 у X). Все аккаунты пишут в ОДИН аккаунт X. Kinguin в X не идёт (там нужны плашки про независимых продавцов, решения не было).
2. Каждое утро в 06:00 (Daily brief) после брифа запускается `scripts/x-sheet.mjs`: берёт `drafts/post-<аккаунт>-x.md` ВСЕХ аккаунтов с каналом `x`, делает каждый пост ОДНОЙ строкой (в таблице у ячейки с переносами строк Google добавляет кавычки, они попали бы в пост), заново проверяет: заканчивается словом `Ad`, ссылка только на нашу страницу `/deals/...`, длина по правилам X (ссылка = 23). Что не прошло, не попадает в список, и это видно в предупреждении запуска.
3. Результат: `x-posts.csv` и `x-posts.json` на ветке `brief` (последние 7 дней, новые сверху; пропущенный день не теряется). Тест: `npm run x:test`, вручную: `npm run x:sheet`.
4. Таблица читает файл сама одной формулой в ячейке A1:
   `=IMPORTDATA("https://raw.githubusercontent.com/alexbogota/saveandplay/brief/x-posts.csv")`
   Столбцы: day, account, post, chars. Владелец копирует ячейку `post` и вставляет в X. Таблица обновляется сама (Google кеширует до часа).
5. Ссылка для профиля X: `saveandplay.com/go/x` (в `public/go/.htaccess`, метка `x-prices`).

## Новая ниша или аккаунт
Скопировать блок `x` из `cozy` в новый аккаунт и поменять `utmSource`/`subid` (например `x-hardware`), теги и `factTags`. Код и таблица не меняются: аккаунт подхватывается сам.

## Что нужно знать
- Адрес файла работает, пока репозиторий публичный (с 20 октября он временно открыт). Если репозиторий закроют, файл надо будет отдавать из публичного репозитория `saveandplay-feeds` или с сайта: поменять адрес в формуле.
- Первый файл появляется после ближайшего Daily brief (06:00 по Боготе).
- Текст всегда с пометкой `Ad` последним словом (владелец решил 8 октября: `Ad`, не `#ad`).
- Если при вставке в X попадут кавычки или переносы, это ошибка формата: сказать Claude, формат меняется в одном месте (`flatten` в `scripts/x-sheet.mjs`).
