## Что сделать
Решение владельца (16 октября): цены Loaded показываем так, как они стоят на их странице, без «старой цены» и без их процента скидки (база процента неизвестна, как у Kinguin). Все скидки у ключей условные, поэтому только честная текущая цена.

Этап 1 (сразу): Loaded как магазин со ссылкой.
- Добавить `loaded` в список магазинов сайта через наш редирект `/go/loaded` (deeplink с `subid=site`).
- Адрес партнёрской ссылки (`naiawork.com`, проверить по самой ссылке) добавить в `linkHosts` в `data/deals-rules.json` и в `src/data/affiliate-hosts.mjs`, чтобы ссылки получали `rel="sponsored"`.

Этап 2: ежедневный список игр с их страницы скидок `https://www.loaded.com/cdkeys-deals` (около 64 товаров, цена в USD для региона US, всё лежит в разметке страницы, без JavaScript).
- Делать как с Kinguin: отдельный маленький скрипт, который раз в день читает страницу, пишет файл `data/loaded.json`; `scripts/update-deals.mjs` перепроверяет его своими правилами и добавляет не больше 5 новых игр в день, всего не больше 15; файл старше 36 часов или битый: ничего не меняем.
- Брать из страницы только факты: название, цену, адрес товара. Картинки, логотипы и тексты Loaded не копировать (их Terms, п. 5.7 и 11.2, запрещают копирование без разрешения; явного запрета на автоматическое чтение там нет). Обложки брать так же, как у других магазинов (`npm run covers`).
- Страницу читать один раз в день, нормальным User-Agent с названием сайта, без обхода защиты. Адреса `/catalogsearch/` и с параметрами `q`, `region`, `platforms` в robots.txt закрыты: не ходить.
- Адреса товаров брать прямо со страницы: у каждой карточки (`div.product-item`) есть ссылка `<a href>` вида `https://www.loaded.com/marathon-pc-steam` (проверено 16 октября в браузере). Эти адреса чистые, в robots.txt не закрыты. Хвост адреса говорит о платформе: `-pc-steam` это ключ Steam, `-pc-ww` (WW) уточнять, `-xbox`, `-ps5` и т. п. пропускать. Список между загрузками меняется, поэтому каждый день читать заново, ничего не кэшировать. Цену искать внутри той же карточки (в разметке карточки есть строка с `$` и ценой); если цены нет, игру пропускать. Не выдумывать адрес из названия.
- Отбирать только PC-ключи (в названии `PC`, без Xbox, PlayStation, Nintendo, FC Points и других внутриигровых валют; DLC не брать). Платформы вне Steam (Rockstar, GOG, Microsoft Store, EA) пока пропускать, чтобы не обмануть покупателя.
- Игру сопоставить со Steam по названию (как в `scripts/lib/kinguin.mjs`, если там есть поиск по `steam_id`; если нет, сделать через Steam appdetails с точным совпадением названия, а при неоднозначности пропускать). Фильтры по отзывам и оценке Steam те же, что у других магазинов.
- Что показывать: «$X at Loaded» и подпись «Key from Loaded, price for US region». Без `was`, без процента Loaded, без «lowest», «cheapest», «safe». Если цена Steam известна и ключ дешевле на 30% и больше, можно добавить «N% below the current Steam price (Steam $Y)», как у Kinguin. Если дороже или равно, просто цена. На странице игры плашка про регион и проверку магазина, как у Kinguin.
- Ссылка кнопки: deeplink Admitad на адрес товара на loaded.com (`ulp=`), `subid=site`, через `/go/loaded/<id>`. Принимать только адреса Admitad из `linkHosts` и только на loaded.com.
- В посты Bluesky и Mastodon Loaded пока НЕ добавлять (решит владелец после первых кликов).

Общее для обоих этапов: `npm run build`, у всех `<img>` есть alt, в `dist/` нет партнёрских ссылок без `rel="sponsored"`, push, дождаться выкладки. Обновить `docs/partners.md`, `START.md`, `docs/decisions.md`.

## Что осталось владельцу
- Через 2–3 дня после выкладки проверить в статистике Admitad, что клики с `subid=site` по Loaded доходят.
- Поддержке Admitad и Loaded пока не писать: решение владельца 16 октября, писать только когда пойдёт заметный трафик и клики (Play-Asia ответил, что без трафика говорить не о чем). Тогда попросить товарный фид и письменное разрешение читать страницу скидок. Пока работаем по условиям, которые есть: берём только факты (название, цена, адрес товара), и если Loaded возразит, этап 2 сразу отключаем.
- Твиттер Loaded (`x.com/LoadedEN`) источником не используем: у X нет бесплатного API, чтение страниц программой нарушает их условия, а все те же товары и адреса уже есть на странице скидок.
