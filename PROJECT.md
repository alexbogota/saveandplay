# SaveAndPlay: паспорт проекта

Обновлено: 6 октября 2026. Положите этот файл в корень проекта (рядом с CLAUDE.md) и начинайте любой новый чат или сессию Claude Code фразой: «Прочитай PROJECT.md». Секретов (паролей, ключей API) здесь нет и быть не должно.

## 1. Что это
Англоязычный сайт и аккаунты со скидками на игры для ПК. Цель: заработок на партнёрских ссылках. Принцип: честные цены, пометка #ad, никакой накрутки.

Роли каналов (решение 6 октября): Bluesky нужен как лицо проекта и источник первых покупателей, но не как гарантированный поток трафика. Данные показали, что голые посты со скидками собирают 1–2 лайка. Лучше работают рубрики с голосом и вкусом, один содержательный пост в день, картинка с alt-текстом, ответы под постами крупных аккаунтов. SEO в план не закладываем. Подробные цифры и список аккаунтов: `SOURCES.md`.

Главная цель на ближайший месяц: получить хотя бы одну настоящую продажу от постороннего человека (в Admitad она появляется как pending вскоре после покупки). Это докажет, что способ раскрутки работает. Деньги и выплаты пока не оцениваем.

## 2. Как устроен сайт
- Папка: `C:\saveandplay` (Astro). Описание и дизайн: `CLAUDE.md`, папка `design`.
- Данные скидок: `data/deals.json`. Дата на сайте берётся из поля `checkedAt`, вручную её не меняем.
- Обложки: команда `npm run covers`.
- Выкладка: push в GitHub, GitHub Actions собирает сайт и заливает по FTPS на хостинг Spaceship (`public_html`).
- Страницы: главная, About, Contact, Affiliate disclosure, Privacy. Terms ещё нужна.

## 5. Правила публикации
- В каждом посте с партнёрской ссылкой метка #ad. В профилях и описаниях каналов указано, что аккаунт автоматизирован и ссылки партнёрские.
- Не покупать через свои ссылки.
- Не ставить ссылку магазина туда, где в таблице выше «нет» или «нужно одобрение».
- Любой новый канал сначала добавляется как площадка в Admitad и Sovrn.

## 6. Данные для автоматизации
- Основной источник: товарные фиды самих сетей (GOG: Admitad → Tools → Product Feeds; IndieGala: их фид). Ссылки на фиды хранить только в GitHub Secrets.
- IsThereAnyDeal не используем, пока не проверены его условия: по ним нельзя менять данные и убирать партнёрские метки, комиссия уйдёт им.
- CheapShark: условия использования не подтверждены, его ссылки идут через свой редирект. Не использовать для боевых ссылок.
- «Самая низкая цена за всё время» пока писать нельзя. Копим собственную историю цен (ежедневные снимки в `data/history.json`) и до накопления пишем «lowest price we've tracked».

## 7. План (редакция 6 октября)
Порядок: 1) источники и тематики (`SOURCES.md`, готово) 2) ручной старт: био, закреплённый пост и 14 постов на аккаунт в одном файле 3) через 1–2 недели, если аккаунт ожил, скрипт публикации по расписанию (пароль приложения в GitHub Secrets) 4) позже скрипт черновиков из `deals.json` и истории цен.
Тематики аккаунтов: «Honest prices» (@saveandplay.com, запущен), «Cozy / инди» (лучший отклик по данным), «Retro / DRM-free» (лучше всего подходит GOG). Метки для SubID: `bluesky-prices`, `bluesky-cozy`, `bluesky-retro`.
Автоответы на упоминания в Bluesky запрещены правилами, ответы пишет человек. В био аккаунта указываем, что публикации автоматизированы и ссылки партнёрские.

## 11. Журнал решений
- 6 октября: Twitter/X для проверки трендов недоступен моим инструментам. Тренды берём из RSS (PC Gamer, GamingOnLinux), календаря событий (Wholesome Direct, Next Fest, распродажи) и Bluesky. Вместо X можно присылать скриншоты.
- 6 октября: каталог GOG содержит около 243 игр с тегом cozy, цены в выборке $1,59–14,99. Комиссия с таких игр невысока, поэтому Cozy растим как аудиторию.
- Открыто: запускать ли Cozy и Retro сразу или по очереди, ставить ли партнёрские ссылки в первые посты или через 3–4 дня.
- 6 октября (вечер, ЗАМЕНЕНО записями ниже про один пост в день): владелец хочет, чтобы темы и данные для постов и статей обновлялись автоматически каждый день. Решение: задача по расписанию (раз в день утром по Боготе), которая читает рабочие RSS (PC Gamer, GamingOnLinux) и данные GOG и выдаёт 5–7 тем с причиной «почему сейчас» и черновиком поста. Частота и время ещё не выбраны. Задача только собирает темы, публикует и пишет статьи человек вместе с Claude. Фиды сами по себе к Claude не подключены: без этой задачи их нужно открывать вручную.
- Правило темпа: одна задача за сессию, следующую Claude не предлагает, пока владелец не скажет.
- 6 октября (поздний вечер): ежедневный подбор упрощён по просьбе владельца. Сейчас один аккаунт (Honest prices), поэтому один пост в день, а не 5–7 тем. Claude сам выбирает один вариант: скидку GOG или IndieGala и причину «почему сегодня» из новостей. Владелец проверяет только, что в посте есть дата проверки цены и нет ничего странного. Схема: (1) программа на GitHub раз в день читает источники из `data/sources.json` и скидки из `data/deals.json` и пишет маленький файл, без токенов; (2) Claude читает только этот файл и пишет один пост; (3) владелец копирует пост в Bluesky вручную (автопубликация позже, по плану в §7); (4) через 2–4 недели смотрим лайки и вручную меняем источники. Запуск сначала фразой «пост на сегодня», позже по расписанию. Сделано: список источников и программа проверки лент. Не сделано: сами шаги 1 и 2 ежедневной программы.
- 6 октября (поздний вечер): список источников для четырёх тем лежит в `data/sources.json`. Темы: prices (Honest prices), cozy (Cozy и инди), retro (Retro и DRM-free), hardware (хостинг и железо, четвёртый будущий аккаунт, связан с разделом Servers на сайте). В списке 59 записей: 18 проверено вручную, 36 кандидатов (предложили Gemini, Grok, DeepSeek, Qwen), 5 исключены с причиной. Проверка всех лент: `npm run sources` или GitHub → Actions → Check sources → Run workflow (таблица на странице запуска, раздел Summary). Программа только читает RSS, уважает robots.txt и представляется честным User-Agent.
- 6 октября (поздний вечер): выводы по источникам. Метки «verified» в ответах других ИИ ненадёжны: из 12 проверенных сайтов работают 9, остальные лежат, закрыты robots.txt или публикуют редко. У GOG нет рабочего RSS. Reddit закрыт для автоматического чтения. Cozy слабое место: из новых есть только Indie Hellzone. Другие ИИ используем только для поиска кандидатов, проверку делает программа.
- 6 октября (поздний вечер): инструмент WebFetch у Claude просит разрешения владельца на каждый новый адрес из ответов других ИИ. Не слать десятки адресов сразу: запросы сгорают, если владельца нет рядом. Массовую проверку делаем программой на GitHub.
