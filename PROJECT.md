## 1. Что это
Англоязычный сайт и аккаунты со скидками на игры для ПК. Цель: заработок на партнёрских ссылках. Принцип: честные цены, пометка «Ad» обычным текстом, никакой накрутки.

Роли каналов (решение 6 октября): Bluesky нужен как лицо проекта и источник первых покупателей, но не как гарантированный поток трафика. Данные показали, что голые посты со скидками собирают 1–2 лайка. Лучше работают рубрики с голосом и вкусом, один содержательный пост в день, картинка с alt-текстом, ответы под постами крупных аккаунтов. SEO в план не закладываем. Подробные цифры и список аккаунтов: `SOURCES.md`.

Главная цель на ближайший месяц: получить хотя бы одну настоящую продажу от постороннего человека (в Admitad она появляется как pending вскоре после покупки). Это докажет, что способ раскрутки работает. Деньги и выплаты пока не оцениваем.

## 2. Как устроен сайт
- Папка: `C:\saveandplay` (Astro). Описание и дизайн: `CLAUDE.md`, папка `design`.
- Данные скидок: `data/deals.json`. Дата на сайте берётся из поля `checkedAt`, вручную её не меняем. Файл каждое утро обновляет программа (§11, запись про `update-deals`), вручную только убираем ненужные игры через `exclude` в `data/deals-rules.json`. Перед ручной правкой на компьютере сделать `git pull`.
- Обложки: команда `npm run covers`.
- Выкладка: push в GitHub, GitHub Actions собирает сайт и заливает по FTPS на хостинг Spaceship (`public_html`).
- Страницы: главная, All deals (`/deals/`), страница каждой скидки (`/deals/<магазин>/<название>/`), Guides, Servers, About, Contact, Affiliate disclosure, Privacy, Terms.

## 6. Данные для автоматизации
- Основной источник: товарные фиды самих сетей (GOG: Admitad → Tools → Product Feeds; IndieGala: их фид). Ссылки на фиды хранить только в GitHub Secrets.
- IsThereAnyDeal не используем, пока не проверены его условия: по ним нельзя менять данные и убирать партнёрские метки, комиссия уйдёт им.
- CheapShark: условия использования не подтверждены, его ссылки идут через свой редирект. Не использовать для боевых ссылок.
- «Самая низкая цена за всё время» пока писать нельзя. Копим собственную историю цен (ежедневные снимки в `data/history.json`) и до накопления пишем «lowest price we've tracked».

## 9. Открытые вопросы

- Как исключить отдельные ссылки из обработки скриптом Sovrn, чтобы он не перебивал ссылки Admitad и IndieGala.
- Нужен ли `/go/<магазин>/<id>` для смены сети и учёта кликов, когда Sovrn определится.
- Правила IndieGala по каналам (Terms).
- Fanatical через CJ.
- Mastodon (аккаунт на mastodon.social, 7 октября): владелец дублирует туда посты Bluesky. Проблемы: (1) в ссылках остались метки `bluesky-prices` (UTM и SubID), статистика кликов и продаж смешивается; для Mastodon нужны свои метки (`mastodon-prices`); (2) Mastodon не входит в таблицу каналов §3, прямые партнёрские ссылки магазинов (GOG и другие) туда ставить нельзя, пока площадка не добавлена в Admitad/Sovrn и не проверены правила оффера; пока в Mastodon только ссылки на наш сайт (так и было 7 октября); (3) правила самого сервера mastodon.social про рекламу и автоматизацию не проверены. Решение на будущее (когда владелец скажет): в `data/accounts.json` ввести каналы аккаунта (bluesky, mastodon) с собственными `subid` и UTM, чтобы brief сразу давал готовые ссылки для каждого канала; тексты под канал (хэштеги в CamelCase, alt-текст к картинкам, длина) тоже брать из настроек канала.

## 10. Идеи на потом
Раздел «Постеры» (Displate, 25%, подавать напрямую после появления раздела). Раздел «Свой сервер» (WiseHosting 10%, Apex Hosting 15%, Godlike.Host в Admitad). Epic Creator Code при 1000 подписчиков.
Полная автоматизация постов и статей через Claude API в GitHub Actions: программа вызывает Claude по brief, получает черновик поста или статьи и присылает его владельцу на одобрение одной кнопкой (Pull Request или аналог), копировать brief в чат больше не нужно. Отложено 7 октября: у владельца пока нет ключа Anthropic API. Когда появится: ключ только в GitHub Secrets, заранее прикинуть расходы на токены, одобрение человеком оставить.

## 12. Для нового чата (состояние на 7 октября, днём)
**Как работать с владельцем.** Он новичок, говорит по-русски. Объяснять просто и коротко, предлагать ОДИН выбранный вариант, одинаковый формат ответов, экономить токены. Текст сайта и постов только английский. Предлагать сразу то, что очевидно нужно проекту и ведёт к автоматизации (решение 7 октября); идеи вне целей проекта не предлагать. ГЛАВНЫЙ ПРИНЦИП: не просить владельца делать что-то вручную, строить автоматизацию, пригодную и для других ниш (подробности в §11, запись от 7 октября). Владелец живёт в Колумбии; выплаты: PayPal, Payoneer, банковские счета в Колумбии и Испании (страна выплат не фильтр для программ).

**Схема.** Программа в GitHub каждый день читает источники и цены и собирает бриф (1). Claude читает только бриф и пишет один пост с причиной «почему сегодня», ссылкой и строкой Ad (2). Владелец публикует вручную в Bluesky, при желании и в Mastodon (3). Автопостинга ботом нет, на комментарии отвечает человек. Через 2–4 недели разбор лайков и кликов (4). Запуск: фраза «пост на сегодня».

**Что работает.** Сайт сам обновляет цены GOG и IndieGala каждое утро в 04:30 по Боготе (`update-deals`), деплой идёт сам; 7 октября на сайте 52 записи, новые игры с обложками появились. Бриф для поста собирается в 06:00. Все четыре workflow на месте в `.github/workflows` (check-sources, daily-brief, update-deals, deploy).

1. Commit и push всех файлов, если ещё не сделано (если push не проходит: `git pull --rebase`).
2. Заявки в партнёрские программы по группе А из §3а.
