A game can be cheap, well reviewed and still a poor buy if you plan to play it on a handheld. If you own a Steam Deck, the first question is not the price. It is whether the game works there.

Valve answers that with a rating on each reviewed game. The labels are short, and it is easy to read more into them than they say. This guide shows what each rating means in Valve's own words, what a game has to pass to get the top one, and how to check before you pay.

## The short version

- **Verified** means Valve says the game "works great on Steam Deck, right out of the box."
- **Playable** means it "may require some manual tweaking by the user." It works, but expect some setup.
- **Unknown** is not a bad score. Valve's wording is "We haven't checked this game for compatibility yet."
- **Unsupported** means "currently not functional" on the Deck. Do not buy it for that device.

## What each rating says

Valve's player-facing page lists four categories. Verified: "The game works great on Steam Deck, right out of the box." Playable: "The game may require some manual tweaking by the user to play", for example choosing a community controller configuration. Unsupported: "The game is currently not functional on Steam Deck." Unknown: "We haven't checked this game for compatibility yet."

Valve's page for developers adds detail. For Playable, it says the game "functions on Deck/Machine, but may require manual work from the user", such as using the touchscreen to get through a launcher. For Unsupported, it says the game "does not function on this device due to incompatibility with Proton or specific hardware components." Proton is the compatibility layer that runs Windows games on Linux-based SteamOS.

## What a game has to pass for Verified

The developer page lists a checklist. A few items, in Valve's words:

- **Controller:** "The default controller configuration must provide users with the ability to access all content."
- **Performance:** "the game must ship with a default configuration that results in a playable framerate."
- **Text:** "the smallest on-screen font character should never fall below 9 pixels in height at 1280x800."
- **Launchers:** if the game opens a launcher first, it must also meet the requirements, "including full navigability with a controller."

So Verified is a statement about the default experience on the handheld: controller, readable text, a playable frame rate, no fiddling. It is not a statement about how good the game is.

## What the rating does not tell you

- **Whether you will like it.** Read the reviews separately. Our guide to [how to read Steam reviews](/guides/how-to-read-steam-reviews/) covers that.
- **Anti-cheat.** It is not a checklist item, but Valve's FAQ says "Some anti-cheat providers are currently unsupported," and that can lead to an Unsupported rating for online games.
- **Future changes.** Proton is described on the same page as "a work in progress", and a patch from the developer can change a game's behaviour either way.
- **Your own setup.** The rating is about the Deck. A different handheld or a desktop PC is not the same case.
- **Unknown games.** No rating is not a warning, but it is also not a promise. You are the tester.

## Where to see the rating

Valve says that in your Library on the Deck you automatically see each game's rating and can filter by it. In the store, you can see compatibility details for every title that has been reviewed, and the first tab of the Steam Store shows only games that are great on Steam Deck.

One caution from our own reading: the This War of Mine store page, as our tool received it on November 8, 2026, showed no Deck rating at all, and the only related system line was "SteamOS + Linux" with Ubuntu 16.04 requirements. The rating may be loaded by the store in a way our tool could not see, so check it in the Steam app or a browser, not from a copy of the page.

## A five-minute check

1. Open the game's page in the Steam app or your browser and look for the Steam Deck rating.
2. If it says Verified, you are done with compatibility.
3. If it says Playable, read what is needed: controller layout, a launcher, small text.
4. If it says Unsupported, skip it for the Deck.
5. If it says Unknown, check community reports and the reviews that mention the Deck.
6. If you buy and it does not work, the refund rules still apply. See [how Steam refunds work](/guides/how-steam-refunds-work/).

## What we did not check

We did not own or test a Steam Deck, so we have not verified that any specific game behaves as its rating says. We read two Valve pages and one Steam store page, and we quote only short lines from the checklist. We did not check how other handhelds or other stores handle compatibility. Valve can change its categories at any time.
